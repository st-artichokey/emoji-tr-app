## Core Feature — Flag Emoji Translation

### Add flag emoji reaction translation using DeepL

Built the core translation feature: react to any message with a country flag emoji to auto-translate it. The bot auto-detects the source language and posts the translation as a threaded reply.

- Created `listeners/languages.js` with source/target language maps and flag-to-language mapping for 40+ country codes (both `fr` and `flag-fr` formats)
- Created `listeners/translate.js` with `stripSlackFormatting()` to clean Slack mrkdwn and `translateText()` wrapper around the DeepL SDK
- Created `listeners/events/reaction-added.js` as the core reaction handler
- Created `listeners/events/channel-join.js` with `joinAllPublicChannels()` (paginated) and `channelCreatedCallback()` to auto-join channels
- Created `listeners/events/app-home-opened.js` with App Home tab showing usage instructions and supported flag list
- Created `listeners/events/index.js` to register all event listeners
- Updated `app.js` to register listeners and auto-join channels on startup
- Updated `manifest.json` with required OAuth scopes and event subscriptions

## Slash Command Feature

### Add /translate command with modal for any-to-any translation

Added a `/translate` slash command that opens a modal dialog for translating text between any DeepL-supported languages (not just flag-mapped ones).

- Created `listeners/commands/translate-command.js` — opens the modal on slash command invocation
- Created `listeners/views/translate-modal.js` — handles modal submission, translates text, and DMs the result
- Created `listeners/views/index.js` — registers the `translate_modal` view callback
- Modal includes source language dropdown (with Auto-detect default), target language dropdown, and multiline text input
- Shows inline modal errors via `response_action: 'errors'` if translation fails

**Sources:**
- [Slack slash commands](https://api.slack.com/interactivity/slash-commands) — registering and handling `/translate`
- [Slack modals (views.open)](https://api.slack.com/methods/views.open) — opening a modal in response to a slash command trigger
- [Slack Block Kit modal reference](https://api.slack.com/surfaces/modals) — `type: 'modal'` view with `input` blocks
- [Slack `input` block](https://api.slack.com/reference/block-kit/blocks#input) — `static_select` for language dropdowns, `plain_text_input` with `multiline` for text
- [Slack view submission handling](https://api.slack.com/surfaces/modals#interactions) — `view_submission` callback with `response_action: 'errors'` for inline validation
- [DeepL source languages](https://developers.deepl.com/docs/getting-started/supported-languages#source-languages) — all available source language codes for the dropdown
